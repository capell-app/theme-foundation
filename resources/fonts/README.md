# Foundation font bundle

These WOFF2 files are self-hosted copies of the open-licensed families named
by the first-party theme presets. Each file is converted from the variable TTF
in the corresponding official Google Fonts repository directory with its
variation axes intact. The IBM Plex Mono static weights are kept separate
because the upstream Google Fonts release does not publish a variable Mono
file.

The accompanying `licenses/` directory contains the upstream SIL Open Font
License text for every family. Sources:
